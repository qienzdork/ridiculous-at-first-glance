# Ridiculous at First Glance, Real by the Second

A single-sentence startup pitch for the make.fun bounty of the same name:
bottled rain-smell sold to windowless offices — absurd at first glance,
until you remember the workers inside never see daylight and will happily
pay to pretend the weather still exists.

`main.py` writes the pitch to the path in `OUTPUT_PATH`
(default `/output/entry.txt`). The entry is one sentence, well within the
1–200 character gate.
